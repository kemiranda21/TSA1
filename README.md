# Tasks for Today Management System

A task-management web application built with CodeIgniter 4 and MySQL.

## Features

- Welcome page showing today's tasks
- Complete task list showing all tasks
- Demo user profile
- About developer page
- MySQL database with migrations and seeders

## Technologies Used

- PHP 8.2
- CodeIgniter 4.7.4
- MySQL
- XAMPP
- Visual Studio Code
